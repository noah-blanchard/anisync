# Booster artwork

Every image here is a reproduction of a public-domain painting or print (the artists died more than 70 years
ago and the works were published before 1929). Files are cropped to the pack window (8:7) and saved as WebP.

| File | Work | Source file |
|---|---|---|
| decouverte.webp | Katsushika Hokusai, *The Great Wave off Kanagawa* (c. 1831) | github.com/lengstrom/fast-style-transfer, `examples/style/wave.jpg` |
| saison.webp | Wassily Kandinsky, *Composition VII* (1913) | github.com/cysmith/neural-style-tf, `styles/kandinsky.jpg` |
| retro.webp | J. M. W. Turner, *The Wreck of a Transport Ship* / *Shipwreck of the Minotaur* (c. 1810) | github.com/lengstrom/fast-style-transfer, `examples/style/the_shipwreck_of_the_minotaur.jpg` |
| cinema.webp | Henri Matisse, *Woman with a Hat* (1905) | github.com/cysmith/neural-style-tf, `styles/woman-with-hat-matisse.jpg` |
| isekai.webp | Vincent van Gogh, *The Starry Night* (1889) | github.com/jcjohnson/neural-style, `examples/inputs/starry_night.jpg` |
| frissons.webp | Edvard Munch, *The Scream* (1893) | github.com/cysmith/neural-style-tf, `styles/the_scream.jpg` |
| ecchi.webp | Francis Picabia, *Udnie* (1913) | github.com/lengstrom/fast-style-transfer, `examples/style/udnie.jpg` |

To add or replace one: drop the image here and set `art: { src: "/boosters/<file>", credit: "…" }` on the booster
in `lib/boosters.ts`. Use artwork you are allowed to use, and list it in this table.
